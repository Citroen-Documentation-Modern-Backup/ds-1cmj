3. Vérifications
ATTENTION : Nettoyer soigneusement chaque pièce à l’aide des produits spécifiques homologués.
ATTENTION : Nettoyer les plans de joint avec le produit décapant homologué. Ne pas utiliser d’outil tranchant ou abrasif. Les plans de joint ne doivent comporter ni trace de choc ni rayure.
3.1. Carter-cylindres
Figure : b1bg3pqd
Contrôler la planéité du carter-cylindres (32) (côté culasse) ; À l’aide d’un jeu de cales et d’une règle  (voir figure).
NOTA : Déformation maximale admise = 0,05 mm (Aucune rectification admise du plan de joint supérieur du carter-cylindres).
Vérifier les points suivants :
  • Vérifier l’absence d’arrachement de métal (Cylindres - Paliers)
  • Mesurer l’usure des différentes pièces (Cylindres - Paliers)
  • Vérifier les différents canaux de lubrification
  • Vérifier l’étanchéité du carter-cylindres (Test d’étanchéité par mise sous pression)
  • Vérifier l’absence de fuites des bouchons cuvettes
Remplacer les pièces défectueuses.
3.2. Attelage mobile
Vérifier les points suivants :
  • Vérifier l’absence d’arrachement de métal (Pistons ; Axes de pistons ; Segments ; Bielles ; Demi-coussinets ; Cales latérales ; Vilebrequin)
  • Mesurer l’usure des différentes pièces (Pistons ; Axes de pistons ; Segments ; Bielles ; Demi-coussinets ; Cales latérales ; Vilebrequin)
Remplacer les pièces défectueuses.
