B1JG018XP0Dépose - repose : Ligne d’échappement
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel : Lève-organe.
2. Silencieux d’échappement
Mettre le véhicule sur un pont élévateur.
2.1. Dépose
IMPERATIF : Attendre au minimum une heure avant toute intervention sur la ligne d’échappement.
Figure : b1jg0o6d
Placer le lève-organe sous le silencieux d’échappement (2).
Déposer les 3 vis (1).
Figure : b1jg0o7d
Désaccoupler les suspentes (3) du silencieux d’échappement (2).
Déposer le silencieux d’échappement (2) ; (avec le joint d’étanchéité) ; À l’aide du lève-organe .
2.2. Repose
ATTENTION : Respecter les couples de serrage .
Figure : b1jg0o8d
ATTENTION : Remplacer systématiquement le joint (4).
ATTENTION : Remplacer systématiquement les 3 vis (1).
Reposer :
  • Le joint d’étanchéité (4) du silencieux (2) (Neuf)
  • Le silencieux d’échappement (2) ; À l’aide du lève-organe
  • Les 3 vis (1)
ATTENTION : Remplacer les suspentes d’échappement défectueuses.
Accoupler les suspentes (3).
Enlever le lève-organe.
Démarrer le moteur.
Contrôler l’absence de fuite.
3. Ligne d’échappement intermédiaire
3.1. Dépose
IMPERATIF : Attendre au minimum une heure avant toute intervention sur la ligne d’échappement.
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie de servitude .
Déposer les sonde à oxygène amont et aval  (selon équipement).
Soutenir la ligne d’échappement intermédiaire ; À l’aide du lève-organe ).
Figure : b1jg0o9d
Déposer les 3 vis (1).
Désaccoupler la suspente (5).
Déposer le joint (4).
Figure : b1jg0owd
Déposer :
  • Les écrous (6)
  • Le joint d’étanchéité du tube avant d’échappement
Figure : b1jg0oxd
Déposer :
  • La vis (7)
  • La ligne d’échappement intermédiaire (8) ; À l’aide du lève-organe
3.2. Repose
ATTENTION : Respecter les couples de serrage .
Figure : b1jg0o8d
ATTENTION : Remplacer systématiquement le joint (4).
ATTENTION : Remplacer systématiquement les 3 vis (1).
ATTENTION : Remplacer systématiquement : Le joint d’étanchéité du tube avant d’échappement .
Reposer :
  • Le joint d’étanchéité (4) du silencieux (2) (Neuf)
  • La ligne d’échappement intermédiaire (8) ; À l’aide du lève-organe
  • Les 3 vis (1) (neuves)
  • Le joint d’étanchéité du tube avant d’échappement  (neuf)
  • Les écrous (6)
  • La vis (7)
Accoupler la suspente (5).
Enlever le lève-organe.
Reposer les sondes à oxygène amont et aval  (selon équipement).
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie de servitude.
Rebrancher la batterie de servitude .
Démarrer le moteur.
Contrôler l’absence de fuite.
