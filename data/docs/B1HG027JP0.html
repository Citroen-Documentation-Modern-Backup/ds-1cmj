3. Repose
ATTENTION : Respecter les couples de serrage .
Repositionner le réservoir à carburant (17).
Reposer :
  • Les écrous (16)
  • Les sangles (13)
  • Les écrous (15)
  • Les câbles de frein de stationnement
  • Les écrous (14)
Retirer l’outil de levage.
ATTENTION : Remplacer les colliers (9), (12).
Déposer les obturateurs [0189-Q].
Accoupler les durits (10), (11).
Reposer les colliers (9), (12).
Reposer :
  • L’arbre de transmission longitudinal  (selon équipement)
  • Les écrans aérauliques (8) (droit et gauche)
  • La ligne d’échappement intermédiaire (7)
  • Le véhicule sur ses roues
Accoupler :
  • Le raccord encliquetable (5)
  • Les raccords encliquetables (6) (en "e")
Connecter le connecteur  (en "c", "d").
NOTA : Appliquer un cordon de pâte d’étanchéité sur le pourtour de la trappe de visite (si nécessaire).
Reposer les 2 trappes de visite (1), (2).
Remplir le réservoir à carburant .
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie de servitude .
Vérifier le bon fonctionnement des jauges à carburant.
Contrôler l’absence de fuite.
