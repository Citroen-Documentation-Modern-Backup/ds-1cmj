B3FG01JFP0Dépose - repose : Pédalier
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Déposer la garniture inférieure de planche de bord côté conducteur.
2. Pédale d’embrayage
2.1. Dépose
Figure : b3fg290d
Désaccoupler : Le tube d’alimentation de l’émetteur d’embrayage (en "b" et "a") (prévoir l’écoulement du liquide de frein).
Figure : b3fg291d
Déposer la vis (1) (selon version).
Écarter le boîtier (2) (selon version).
Figure : b3fg292d
Déposer les 3 vis (3).
Écarter : Le boîtier de servitude intelligent (4).
Figure : b3fg293d
Dégrafer le connecteur  (en "c").
Désaccoupler : La rotule de l’émetteur hydraulique d’embrayage (en "d").
Déposer les 6 écrous (6).
Tourner : L’émetteur d’embrayage (7) (Déverrouiller d’un quart de tour).
Dégager : L’émetteur d’embrayage (7).
Déposer la pédale d’embrayage (5).
2.2. Repose
Reposer :
  • La pédale d’embrayage (5)
  • Les 6 écrous (6)
  • L’émetteur d’embrayage (7)
Tourner : L’émetteur d’embrayage (7) (Verrouiller d’un quart de tour).
Accoupler : La rotule de l’émetteur hydraulique d’embrayage (en "d").
Agrafer le connecteur  (en "c").
Reposer :
  • Le boîtier de servitude intelligent (4)
  • Les 3 vis (3)
  • Le boîtier (2)
  • La vis (1)
Accoupler :
  • Le tuyau d’alimentation de l’émetteur d’embrayage (7)(en "a")
  • Le tuyau d’alimentation de l’émetteur d’embrayage (7)(en "b") ; À l’aide d’une pince
Reposer :
  • Le boîtier (2) (selon version)
  • La vis (1)  (selon version)
Remplir et purger le circuit de freinage .
3. Pédale de frein
3.1. Dépose
Figure : b3fg294d
Déposer le contacteur de feux stop (8) .
Dégrafer le faisceau électrique  (en "e").
Déposer :
  • La goupille (9)
  • L’axe (10)
  • Les 6 écrous (11)
  • La pédale de frein (12)
3.2. Repose
Reposer :
  • La pédale de frein (12)
  • Les 6 écrous (11)
  • L’axe (10)
  • La goupille (9)
Agrafer le faisceau électrique  (en "e").
Reposer le contacteur de stop (8) .
4. Pédale d’accélérateur
4.1. Dépose
Figure : b3fg295d
Déconnecter le connecteur  (en "f").
Déposer :
  • Les 3 vis (13)
  • La pédale d’accélérateur (14)
4.2. Repose
Reposer :
  • La pédale d’accélérateur (14)
  • Les 3 vis (13)
Reconnecter le connecteur  (en "f").
5. Opérations complémentaires
Reposer : La garniture inférieure de planche de bord (Côté conducteur).
