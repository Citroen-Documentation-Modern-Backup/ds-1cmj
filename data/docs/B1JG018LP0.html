IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel : Lève-organe.
2. Silencieux d’échappement
Mettre le véhicule sur un pont élévateur.
2.1. Dépose
IMPERATIF : Moteur chaud : Attendre au minimum une heure avant toute intervention sur la ligne d’échappement.
Figure : b1jg0n3d
Placer le lève-organe sous le silencieux d’échappement (2).
Désaccoupler les suspentes (1) du silencieux d’échappement (2).
Figure : b1jg0n4d
Déposer :
  • Les 3 vis (3)
  • Le silencieux d’échappement (2) (avec le joint d’étanchéité) ; À l’aide du lève-organe
2.2. Repose
ATTENTION : Respecter les couples de serrage .
Figure : b1jg0n5d
ATTENTION : Remplacer systématiquement le joint d’étanchéité (4).
ATTENTION : Remplacer systématiquement les 3 vis (3).
Reposer :
  • Le joint d’étanchéité (4)
  • Le silencieux d’échappement (2) ; À l’aide du lève-organe
  • Les 3 vis (3)
ATTENTION : Remplacer les suspentes d’échappement défectueuses.
Accoupler les suspentes (1).
Enlever le lève-organe.
Démarrer le moteur.
Contrôler l’absence de fuite.
Reposer le véhicule sur ses roues.
